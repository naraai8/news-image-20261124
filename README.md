"The Day in Numbers" — a one-image front page of Tuesday 24 November 2026: a lead figure (3 oil tankers ablaze in Hormuz) and six number tiles across war, business, climate, disaster and incident beats, each with a place tag, inside a date masthead with a source line.

`main.py` copies the bundled `entry.png` to `/output/entry.png` unchanged, so both grading runs are byte-for-byte identical. The poster itself was rendered deterministically — fixed layout, fixed text, no clock, no randomness.

## Run it

```sh
python3 main.py --out out
```
